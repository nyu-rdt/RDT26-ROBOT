On the GCS: 
If the workspace doesn’t exist already (clones repo of the branch):
cd ~/Desktop
mkdir rdt_gcs_ws_wip

git clone -b wip https://github.com/nyu-rdt/RDT25-GCS.git
	

BEFORE YOU BUILD AND TEST CHECKLIST
* Make sure nyurdt_localization/apriltag_detector.py has the right camera uncommented
* Make sure nyurdt_autonomy_handler/GCS_command_subscriber.py has the right subprocess command uncommented (not the one that is just ‘excavation’)


subprocess.Popen(['ros2', 'run', 'nyurdt_autonomy', 'excavation_sensor'])
	

Run joystick manual control:
cd ~/Desktop/rdt25_gcs_ws_michael_wip/
colcon build
isb
ros2 run nyurdt_gcs_manual_control joystick_main
	

New terminal tab
Run joy node (no need to run isb):
ros2 run joy joy_node
	

New terminal tab
Run joy subscriber to see if sensor data is received:
isb 
ros2 run nyurdt_gcs_manual_control joystick_sub
	

Press Exit button after setting up pi to get sensor data (should show up in joystick_sub terminal)
